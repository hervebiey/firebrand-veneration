# Firebrand — Veneration Night with the King

VNC Firebrand's worship evening: the public set list with per-song pages and a
built-in audio player, plus the choir's songbook (lyrics, keys, voice parts and
practice tracks).

Built with Next.js (static export), React, Tailwind CSS and wavesurfer.js.

## Getting started

First install the npm dependencies:

```bash
npm install
```

Next, run the development server:

```bash
npm run dev
```

Finally, open [http://localhost:3000](http://localhost:3000) in your browser to
view the website.

## Other scripts

```bash
npm run build   # static export to ./out
npm run lint    # eslint
```
